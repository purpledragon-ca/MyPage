> 复现 GitHub 上的相机–激光雷达标定方法，适配到相机 + 2D 激光雷达方案，并整理为内部 SOP 文档。

## 简介

本项目基于开源 **[CamLaserCalibraTool](https://github.com/MegviiRobot/CamLaserCalibraTool)**，目标是得到相机与 2D 激光雷达之间的外参（R、T），用于后续多传感器融合。

- 传感器：机载相机 + 2D 扫描激光雷达  
- 标定物：棋盘格标定板  
- 输出：激光雷达 → 相机外参（旋转 R、平移 T）

## 我的工作

- **方法复现**：按原 GitHub 实现完整跑通流程，在我们自有车体平台上完成从数据采集、标定到可视化的复现。  
- **2D 激光雷达适配**：针对单线扫描、视场有限的 2D 激光雷达调整流程，包括标定板摆放策略、有效点筛选与几何约束。  
- **端到端联合标定**：搭建从相机内参标定 → 激光雷达数据采集 → 外参估计 → 投影验证的完整流程，实现相机与 2D 激光雷达的稳定联合标定。  
- **质量验证**：将 2D 激光雷达扫描点投影到相机图像，检查激光线与场景边缘/棋盘格轮廓的对齐情况，确保标定精度满足产品要求。  
- **内部 SOP 编写**：将全流程整理为公司 SOP，涵盖硬件布置、场地要求、采集步骤、标定参数与常见问题，便于测试与生产团队一致、高效地执行标定。
